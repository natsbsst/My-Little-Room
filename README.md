# My Little Life — квартира

Unity-проект квартиры с ручным управлением и автономным персонажем.

## Запуск

1. Откройте корень репозитория через Unity Hub в Unity **6000.4.2f1**.
2. Дождитесь импорта пакетов и откройте `Assets/Scenes/SampleScene.unity`.
3. Нажмите Play, затем «Начать игру».

Игра работает без запуска сервера. Текущая сцена к серверу не обращается;
подключение базы данных планируется отдельно.

## Управление

- WASD — движение относительно камеры.
- Удерживать правую кнопку мыши — поворот камеры.
- Пробел — прыжок с пола в ручном режиме.
- Tab — ручной режим / Utility AI.
- E — действие у мебели; отход отменяет действие.
- Esc или шестерёнка — игровое меню.

Потребности находятся справа. Выбор стратегии при одинаковой полезности действий
доступен в настройках и описан на русском. Стартовое меню показывает город из
Unity, игровое меню затемняет сцену. Фоновая музыка отключена.

## Потребности и время

Начальные значения: сытость 78, гигиена 92, сон 100, работа 85, досуг 82.
Потребности зависят от игровых часов: еда расходуется быстрее, усталость
накапливается к ночи. Сон получает больший приоритет вечером и ночью.
Игровые сутки занимают 180 секунд при обычной скорости. Меню останавливает время.

Часы скрыты из интерфейса. `DayNightCycle` предоставляет `CurrentHour`,
`CurrentDay`, `TotalGameHours` и `SessionPlaySeconds` для будущих записей в БД.
Счётчики относятся к текущему запуску; запись в БД и сохранение сессии между
запусками пока не подключены.

## Проверки

В Unity проверены ручные действия, отмена, пауза, автономное движение,
прыжок и переходы через главное меню. Проверен маршрут
диван → кровать → диван → душ → диван с физическими коллайдерами дверей.

Дополнительные проверки доступны в меню `My Little Room → Life`:

- `Check character in Play Mode`;
- `Check jump in Play Mode`;
- `Check menus needs and door routes` — запускается со стартового экрана.

Для первых двух проверок сначала начните игру. Проверки временно управляют
персонажем в Play Mode, не сохраняют его перемещения в сцену.

## Unity MCP

В `Packages/manifest.json` закреплена версия MCP for Unity. Для подключения
ассистента настройте плагин через `Window → MCP for Unity`; персональные
настройки Codex и учётные данные в репозиторий не включаются.
